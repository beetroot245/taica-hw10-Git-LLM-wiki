# Git 教學 Wiki

這條學習路徑適合第一次使用 Git 的讀者。完成後，你可以在自己的 GitHub 練習儲存庫獨立開出一個 Pull Request（PR）。

[開啟課程地圖與 HTML 教學簡報](../slides/index.html)

1. [安裝與設定 Git](lessons/setup.md) · 讓 Windows PowerShell 找到 Git，認識提交身分和 GitHub 登入。
2. [工作目錄、暫存區與提交](lessons/local-workflow.md) · 用同一個檔案看懂 `git add` 前後的差異，並建立本機提交。
3. [分支、合併與衝突處理](lessons/branches-and-merge.md) · 在本機練習建立分支、合併，以及解決一次文字衝突。
4. [遠端儲存庫](lessons/remotes.md) · 認識 `origin`，分辨下載、推送與整合變更。
5. [實作：開出第一個 GitHub Pull Request](exercises/first-pull-request.md) · 建立分支、提交、推送，核對 PR 的分支和檔案差異。
