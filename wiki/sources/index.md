# Git 教學來源索引

原始 PDF 存放在 `raw/papers/`。下列頁碼以 PDF 閱讀器顯示的檔案頁次為準。

### S01

[寫給 Git 初學者的入門 4 步驟（Max 行銷誌）](<../../raw/papers/[Git教學] 寫給 Git 初學者的入門 4 步驟 - Max行銷誌.pdf>)，11 頁。第 2–6 頁可用於安裝、初始化、暫存、提交、推送與分支的課程安排。本文部分示範使用 `master`，教材須依實際預設分支調整。

### S02

[007 Git 入門指南（飛飛）](<../../raw/papers/[工具應用] 007 Git 入門指南：給資安新手的完整教學 - 飛飛.pdf>)，10 頁。第 3–6 頁涵蓋安裝、身分設定、提交、分支與遠端，第 8 頁提供發 Pull Request 的協作情境。採用一般文字檔作為練習素材。

### S03

[Git 版本控制筆記（越南放大鏡 X 下班資工系）](<../../raw/papers/Git 版本控制筆記：從入門到 GitHub Pages 部署網站｜越南放大鏡 X 下班資工系.pdf>)，29 頁。第 2–8 頁展示工作目錄、暫存區、本機與遠端，第 11–12 頁可參考分支與衝突的範例。Windows 教材將 Git Bash 的檔案操作改寫成 PowerShell。

### S04

[Git 入門教學（2018 年 7 月投影片）](../../raw/papers/git.pdf)，169 頁。依封面及章節整理為補充參考，涵蓋版本庫、工作區與暫存區、遠端倉庫、分支和衝突。現行教材的指令和 GitHub 操作另依官方文件與實測確認。

### S05

[新手也能懂的 Git 教學（FlyotLin）](<../../raw/papers/新手也能懂的Git教學. 由各種使用情境了解Git的使用方法 _ by FlyotLin _ Medium.pdf>)，18 頁。第 4–9 頁有工作流程及差異檢查，第 10–14 頁說明複製、同步、推送與分支。文中將 `git pull` 簡化為抓取加合併，教材補充整合方式也會受設定或參數影響。
